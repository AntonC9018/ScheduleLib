# Issue Tracker

Use [GitHub Issues](https://github.com/AntonC9018/ScheduleLib/issues) and the
authenticated `gh` CLI for ScheduleLib work. The complete workflow is in
[task-management.md](../task-management.md).

Fetch the originating issue and its discussion before reviewing or implementing:

```bash
gh issue view NUMBER --repo AntonC9018/ScheduleLib --comments
```

Follow native parent/sub-issue and blocking relationships. Preserve current
ownership, user scope, and existing decisions when creating follow-up work.
