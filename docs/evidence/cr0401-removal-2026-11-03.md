# CR0401 removal (2026-11-03)

The maintainer rejected automatic stage extraction during case 11 of [#246][rollout].
[CodingRules #43][analyzer-pr] implements the removal for [CodingRules #42][analyzer-issue].

## Change

- Remove CR0401 from supported diagnostics, code-fix registration and diagnostic IDs.
- Remove the block-stage planner and its computed-local/nested-decision threshold.
- Accept block projections with several useful locals or nested decisions. Extraction is a
  manual readability choice; it is not required to satisfy a temporary-count heuristic.
- Preserve CR0400 expression-projection and CR0402 collection-selector diagnostics and fixes.
- Let ordinary CR0400 block fixes keep named intermediate values directly in their lambda.
  A typed helper remains for tuple projections where it preserves inferred tuple element names.
- Convert former CR0401 fixtures into accepted cases, including mapped source, static captures,
  nested decisions and checked arithmetic. Verify that CR0401 is absent from analyzer and fixer
  registration and that ordinary block fixes add no unnecessary local functions.

ScheduleLib adopts freshly packed local-feed version `0.1.0-local.20261103.2` from CodingRules
`aff17ed7da02929a811eecb5c1afbc1569ee33e5`. Its archive SHA-256 is
`b6e8d720b5dc33b14a3e3ce06fa3246e1be93a97e48ff3afc399487b5b83adc5`.
The package reference remains private to consumers. Remove CR0401 from the legacy
warning list because the diagnostic no longer exists; this is not a consumer suppression.
The routed-topic lambda in `AddLessonsToOnlineRegistryHandler.cs` stays unchanged.
