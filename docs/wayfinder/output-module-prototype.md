# Output module — the early PDF-rendering prototype

Recorded 2026-09-05 (grilling session ScheduleLib-6xo.1, Q12: the owner wants a module that outputs the timetable in the exact official-PDF format and remembered an early prototype with a "delayed algorithm to place the lessons").

- **It is literally the repo's first code.** Commit `6250dc9` (2024-12-27) adds `src/App/Generator.cs`, which renders the official `Orar_An_X Lic.docx` layout **directly to PDF via QuestPDF** (no Word step): rotated Romanian day names, roman-numeral time-slot column with intervals, group-name header row, thick borders on day boundaries, 5 group columns per A4 page.
- **Placement = two-phase deferred ("delayed") algorithm.** Phase 1 buckets weekly lessons into cells keyed (DayOfWeek, TimeSlot) × GroupId (`MappingsCreationHelper.CreateCellMappings`, `GeneratorCache.cs:157-196`). Phase 2, at render time, `SharedLayout.Create` (`SharedLayout.cs:14-90`) assigns vertical order: singular lessons on top, shared lessons aligned across all their groups' columns (`MoveToAfterFurthestInGrouping`, :62-86 — a lesson lands one row past the furthest counter among its groups, then every group's counter is bumped). Row heights are split proportionally per cell (`SizeComputer.cs:14-26`). A backtracking search for group-column ordering exists but is disabled (`SharedLayout.cs:128-292`, `bool success = false`).
- **Status: dormant/superseded.** Renamed `GroupColumnScheduleTableDocumentGenerator` (`src/ScheduleLib/ScheduleLib.Generator.Pdf/Generation/GroupColumn/`), zero references outside its folder. The live path is `TeacherCute.Generator` ← `GeneratePdfsForGroupsAndTeachersTaskHandler` ← MainCli — but the prototype's plumbing survives there (`CreateCellMappings`, `SizeComputer`, `FilteredSchedule`, `DayNameProvider`, `LessonTimeConfig`).
- **Relevance for the engine's output step (Q12 flow: engine → new schedule → store → render):** the generator can be reused for official-format output of solver results; its input is a lesson set with (day, slot) already assigned, which is exactly what the engine emits. Format refinements and a visual prototype pass are still pending.
