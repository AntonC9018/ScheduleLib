# Original website timetable capture

These are the unchanged September 21, 2026 PDFs preserved by
[PR #68](https://github.com/AntonC9018/ScheduleLib/pull/68) in its
`src/Features/Tests/ParsePdf/Fixtures` directory. Its fixture README records
the download date; this directory uses that capture date rather than the
PR creation date or an asserted official effective date.

The shared loader now retains this snapshot between the September 1 Word
sources and the October 11 website capture. Year I and II match the later
capture byte for byte. The older year III PDF preserves IA2402's earlier
Cloud lab timetable; the website revision changed its odd/even-week slots
on or before September 25.
