# FMI PDF regression fixtures

Downloaded from https://fmi.usm.md/orar/ on September 21, 2026:
`https://fmi.usm.md/wp-content/uploads/2026/09/orar1.pdf`, `orar2.pdf`, `orar3.pdf`.

`expected-cells.json` preserves the 493 cell records reviewed during the original
import and document QA. These are independent golden expectations for the C# port,
not values regenerated by the C# importer. The third-year website PDF changed
on or before September 25; this fixture intentionally preserves the older revision.
